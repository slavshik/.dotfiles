## How to Use in Blink

### Option 1: Direct Hex Input
In Blink terminal, you can type hex sequences:
```
Send: 0x0231  (selects tab 1)
Send: 0x026A  (focus down)
Send: 0x0234  (selects tab 4)
```

### Option 2: Configure Keyboard Shortcuts
In **Blink Settings → Keyboard → Custom Keyboard Shortcuts**:

```
Action: Focus Left      → Send: \x02\x68  (or 0x0268)
Action: Focus Down      → Send: \x02\x6A  (or 0x026A)
Action: Focus Up        → Send: \x02\x6B  (or 0x026B)
Action: Focus Right     → Send: \x02\x6C  (or 0x026C)
Action: New Tab         → Send: \x02\x63  (or 0x0263)
Action: Next Tab        → Send: \x02\x6E  (or 0x026E)
Action: Prev Tab        → Send: \x02\x70  (or 0x0270)
Action: Tab 1           → Send: \x02\x31  (or 0x0231)
Action: Tab 2           → Send: \x02\x32  (or 0x0232)
... (continue for 3-9)
```

### Option 3: Use as Shell Alias
In your shell profile:
```bash
# Herdr shortcuts (iPad Blink)
alias h-left='printf "\\x02h"'
alias h-down='printf "\\x02j"'
alias h-up='printf "\\x02k"'
alias h-right='printf "\\x02l"'
alias h-tab-new='printf "\\x02c"'
alias h-tab-next='printf "\\x02n"'
alias h-tab-prev='printf "\\x02p"'
```

## Hex Code Anatomy

All sequences start with `0x02` (Ctrl+B, the herdr prefix):
- `0x0268` = `02` (prefix) + `68` (ASCII 'h' = 0x68)
- `0x0234` = `02` (prefix) + `34` (ASCII '4' = 0x34)
- `0x024A` = `02` (prefix) + `4A` (ASCII 'J' = 0x4A, uppercase)

### ASCII Quick Reference
| Char | Hex | Char | Hex | Char | Hex |
|------|-----|------|-----|------|-----|
| 0-9 | 30-39 | h | 68 | H | 48 |

## iPad Pro + Magic Keyboard Setup

1. **Enable Ctrl Key** in Blink → Settings → Keyboard
2. **Create macro shortcuts** for common actions
3. **Use hex codes** as shown in tables above
4. **Test with ESC sequences**: `\x02\x68` (focus left)
5. **SSH-compatible**: Works anywhere herdr is running!
